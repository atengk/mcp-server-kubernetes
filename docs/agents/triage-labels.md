# 问题分类标签体系 (Triage Labels)

各项工程技能围绕 5 种标准分类角色展开。本文档将这些标准角色映射为本项目任务跟踪器中所使用的实际标签字符串。

| 技能规范角色名 | 本仓库实际标签 | 业务含义 |
| :--- | :--- | :--- |
| `needs-triage` | `needs-triage` | 待维护者进行初步评估与分类 |
| `needs-info` | `needs-info` | 等待提报人补充更详细的信息 |
| `ready-for-agent` | `ready-for-agent` | 需求与规范完整，可由自动化 Agent 直接承接 |
| `ready-for-human` | `ready-for-human` | 复杂度高或涉及核心权衡，需要人工开发者介入实现 |
| `wontfix` | `wontfix` | 不予采纳或无需处理 |

当技能要求执行分类动作时（例如“应用就绪 Agent 标签”），直接使用上表右侧对应的标签字符串。

若日后仓库标签策略发生变动，直接修改本表格右侧列即可。
