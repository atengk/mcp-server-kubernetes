# 0008. 受控容器探针命令执行 (Pod Exec) 与安全防御门禁

- **状态**: accepted
- **日期**: 2026-10-06

## 背景与上下文

向运行中的容器注入并执行命令（Pod Exec）是诊断容器内挂载配置、网络连通性（`curl`/`ping`）及进程卡死的关键手段，但若失控或被滥用则存在严重的安全逃逸与命令注入风险。

## 架构决策

提供受严格防御管辖的 `k8s_exec_command` 工具：
1. **独立开关门禁**：默认严格禁用 Exec 功能，必须显式传入 `--allow-exec` 启动参数方可激活注册；
2. **非交互式单次执行**：不支持长连接伪终端（PTY）或交互式 Shell，仅支持一次性无阻塞命令调度；
3. **熔断与限流缓冲**：强制注入 15 秒命令执行超时熔断，且输出缓冲区硬性截断为 64KB，彻底防止死循环进程拖垮服务。

## 架构后果

- **正面收益**：AI 具备深入容器内部环境进行物理探测的最高阶排障能力。
- **潜在代价**：无法执行需要持续交互确认的交互式 CLI 程序。
