# 0003. 细粒度排障工具集设计与运行时安全脱敏守卫

- **状态**: accepted
- **日期**: 2026-10-06

## 背景与上下文

Kubernetes 集群具备复杂多样的资源体系与高危操作风险，AI Agent 容易因模糊的工具签名产生调用幻觉，或因权限失控对生产造成不可逆破坏，亦或因直接读取机密信息导致凭证泄漏。

## 架构决策

1. **细粒度语义化工具集**：对外暴露明确职责的专用 MCP Tools（`k8s_list_resources`、`k8s_get_resource`、`k8s_get_pod_logs`、`k8s_get_events` 等），提供精简且具备强类型校验的 JSON Schema。
2. **只读默认与写权限门禁**：服务端默认以严格只读模式启动；变更型工具（`apply`、`scale`、`delete`）仅在显式配置 `--allow-write` 启动参数时才向 MCP 客户端暴露注册。
3. **Secret 键名保留与敏感数据脱敏**：读取 Secret 资源时，保留元数据与数据键名列表（Keys），但对所有实际数据内容强制进行 `[REDACTED]` 遮蔽。

## 架构后果

- **正面收益**：最大限度防止 LLM 幻觉产生高危写操作；排障信息完整且不泄露机密凭证。
- **潜在代价**：不支持全自动无人值守部署（除非运维人员显式授予 `--allow-write` 权限）。
